THE SOLAR SYSTEM - Interactive 3D

HOW TO USE
1. Unzip and double-click index.html (any modern browser).
2. To publish: drag the solar-system folder onto Netlify Drop, Vercel, Cloudflare Pages or GitHub Pages.

CONTROLS
Drag = orbit, wheel / pinch = zoom, tap a planet = details.
Keys: Left/Right = next planet, T = guided tour, Space = pause, Esc = close.

NOTES
- Needs internet on first load for three.js r128 (cdnjs) and Google Fonts.
- Planet sizes and distances are compressed so everything fits on screen.
- Built with HTML, CSS, JavaScript, Three.js and a small GLSL shader. Textures are embedded in index.html.
- Confirm you have the rights to the supplied images before commercial use.
