# THE SOLAR SYSTEM – INTERACTIVE 3D

An interactive 3D Solar System experience that allows users to explore the Sun and planets in a visually engaging environment. Built using HTML5, CSS3, JavaScript, and Three.js.

 #  FEATURES

- Interactive 3D Experience: Explore the Solar System in a realistic 3D environment.
- Planet Information: Click or tap any planet to discover its details.
- Orbit Controls: Drag to rotate and explore the scene.
- Zoom Functionality: Zoom in and out using the mouse wheel or pinch gestures.
- Guided Tour: Navigate through the planets with an automated tour.
- Keyboard Navigation: Use keyboard shortcuts for smooth navigation.
- Touch Support: Interact with the Solar System using touch controls.

# HOW TO USE

1. Download or Clone this repository.
2. Extract the project ZIP file.
3. Open "index.html" in any modern web browser.
4. Explore the Solar System using mouse, touch, or keyboard controls.

# CONTROLS

Action| Control
Rotate / Orbit| Drag
Zoom In / Out| Mouse Wheel / Pinch
View Planet Details| Tap / Click a Planet
Previous Planet| Left Arrow
Next Planet| Right Arrow
Guided Tour| T
Pause / Resume| Space
Close Details| Esc

# TECHNOLOGIES USED

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive functionality
- Three.js (r128) – 3D graphics and rendering
- GLSL Shader – Visual effects
- Google Fonts – Typography
